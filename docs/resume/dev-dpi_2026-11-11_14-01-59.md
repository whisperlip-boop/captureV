## Root cause
capture/canvas_view.py mousePressEvent/mouseMoveEvent passed `event.position().toPoint()` (rounded) into `mapToScene`.

## Decisions
- PySide6 `mapToScene` has no QPointF overload. `viewportTransform().inverted().map()` is 1 ulp off at non-100% zoom, so it was rejected (DPR 1 risk).
- `_map_to_scene_f(view_pos: QPointF)`: whole-pixel position -> plain `mapToScene(p)` (DPR 1 bit-identical). Otherwise `mapToScene(round(p)) + frac / m11()`, then `round(.., 6)`, because 1/1.5 float error put exact boundaries at 9.999.. (qa-dpi CRITICAL, fixed round 2). Assumes the view transform is a uniform scale.
