# dev-zoom resume note

## Goal
Canvas zoom > 100% (physical pixels) draws pixmap items nearest-neighbor (PicPick-like crisp pixels);
<= 100% stays smooth. Export/copy output must stay byte-identical. No 1px seam regression.

## Decisions
- Single change in `_CanvasPixmapItem.paint` (capture/canvas_view.py ~L56-67).
- Decision: `widget is not None` (on-screen only; scene.render passes None) AND
  `hypot(worldTransform.m11, m12) * painter.device().devicePixelRatioF() > 1 + 1e-6`
  = effective physical px per image px. Equivalent to zoom_percent() > 100 but also covers new items,
  monitor DPR changes and any item transform without hooking the zoom path.
- Nearest path draws pixmap directly (setTransformationMode in paint would call update() -> repaint loop;
  base paint overrides the hint from the item mode). Selection highlight is suppressed anyway.
- L161 view hint and L448 item SmoothTransformation left as is (still used at <=100% and for export).
- Rotation (L1039) is baked into pixels via QImage.transformed(Smooth); no item has setRotation/
  setTransform (grepped), so rotated content is smooth in data and shown nearest above 100% like everything else.
